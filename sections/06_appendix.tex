\section{Appendix: Quick Reference \& Troubleshooting}

\subsection*{Common Error Messages}

\textbf{``Missing \$ inserted''} -- You used a special character (like \_ or \^{}) outside of math mode. Either escape it (\textbackslash\_) or wrap in dollar signs (\$x\_1\$).

\textbf{``Undefined control sequence''} -- You used a command that doesn't exist, often a typo. Check spelling and make sure the required package is loaded.

\textbf{``Missing \} inserted''} -- You forgot to close a brace somewhere. Count your \{ and \} to find the mismatch.

\textbf{``Reference undefined''} -- You referenced a label that doesn't exist, or you need to compile again. Check for typos in your \textbackslash ref\{\} commands.

\textbf{``Citation undefined''} -- The citation key doesn't match anything in your .bib file. Check for typos and make sure your .bib file is saved.

\subsection*{Special Characters}

These characters have special meaning in \LaTeX{} and need to be escaped:

\begin{tabular}{ll}
\toprule
\textbf{Character} & \textbf{How to type it} \\

\bottomrule
\end{tabular}

\subsection*{Exporting from R}

If you use R, these packages can export \LaTeX{} tables directly:

\begin{itemize}
    \item \texttt{kableExtra} -- great for simple tables
    \item \texttt{gtsummary} -- perfect for Table 1 demographics
    \item \texttt{stargazer} -- good for regression output
    \item \texttt{xtable} -- the classic option
\end{itemize}

From any coding language, export figures as PDF (not PNG/JPEG) when possible---they scale better and look sharper in the final document.
